Endeavor tracker guide

How the tracker works for the GM and for players.

Tracks For players For the GM Good to know

Tracks

An endeavor is a name, an objective and one or more tracks. A track is a row of boxes that fills toward a threshold. There are three kinds:

  • Success (green): fills toward the endeavor's threshold.
  • Failure (red): an optional limit on failures.
  • Clock (yellow): the Mission ticking clock.

When a failure track or clock fills, the endeavor is tagged Failed. When every success track is full, it is tagged Succeeded. The tag is only a flag. Nothing locks, and the GM decides what happens next.

For players

You see the endeavors and tracks the GM has shared, and the objectives checklist. The view is read-only. The endeavor with the purple outline and the Active tag is the one in play.

Click an endeavor's name to fold it away or open it again. That only changes your own view.

For the GM

Start an endeavor

New endeavor
Pick a type and a difficulty. The difficulty sets the success threshold: Simple 4, Average 8, Intricate 9, Insurmountable 11. The type picks the starting tracks. Every label and threshold can be edited, and you can add or remove tracks, for example one small success track per sub-objective.
Objectives checklist
Optional lines to tick off, such as primary and secondary Mission objectives.
GM notes
Shown only in the GM view.

Run it

−1, +1, +2
Every track has −1 and +1. Success tracks also have +2 for a spectacular success.
Shown / Hidden
Each track has its own switch, so you can share the successes and keep the failure count to yourself. Hide on the endeavor hides the whole thing.
Pin
The pinned endeavor is the active one. It sits at the top for everyone and starts open.
Change log
The last 12 ticks and checklist changes, with who and when. Undo reverses that one change.
Archive and Delete
Archive puts an endeavor away under Archived, where it can be restored. Delete asks for a second click and cannot be undone.

Good to know

  • Endeavors are stored in the Owlbear room, not the scene, so they stay when you change scenes.
  • Hidden tracks, hidden endeavors and GM notes are hidden in the interface only. They are stored where a player using browser developer tools could read them. At the table this is the same trust as a GM screen.
  • Only the GM's view has controls. Owlbear does not enforce this, so it is a table convention too.
  • Owlbear gives a room 16 kB of storage, shared by all extensions. The GM view shows how much the tracker uses. Archived endeavors still count, so delete the ones you no longer need.
  • Tracks are not linked to map tokens yet.
